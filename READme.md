# Groove

A browserbased mini music studio built with HTML, CSS and JavaScript.

Groove is a simple music creation tool that runs entirely in the browser. It allows users to play a virtual piano, record notes, create drum patterns, control the tempo and save compositions.

## Features

* Virtual piano

## Tech Stack

* HTML
* CSS
* JavaScript
* Web Audio API
* Local Storage
